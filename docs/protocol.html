Telemetry Protocol

STM32H723 Log Viewer

Overview

The flight controller sends FlightData_t as raw bytes over UART1 using DMA. No protocol wrapping — the struct is the packet. Little-endian (ARM Cortex-M7), packed with #pragma pack(push, 1), no padding.

Packet size
85 B
Baud rate
115200
Max rate
~135 Hz
Byte order
Little-endian

Framing

0xFE0xCA
...
0xBE

Sync word 0xCAFE at offset 0 (little-endian on wire: 0xFE then 0xCA). Footer byte 0xBE at offset 84. No length field, no checksum, no CRC — fixed-size packet.
